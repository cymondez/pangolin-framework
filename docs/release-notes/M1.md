# M1 API 增量與相容性

基線 v1.3、產品目標 v0.1.0。保留 M0 的 Module／DI／Config／Host／UOW／Scope 公開 Port 簽章；新增實作與建構入口，完整 surface 由 `tests/contract/api.json` 固定。

- `module.NewRegistry`：穩定逐層拓撲排序與 ADR02 的版本語法。
- `di.NewRegistry(cleanupTimeout)`：明確 Provider 相依、Replace 原因、Singleton／Transient／Operation 與單一清理 owner。
- `config.NewLoader`／`StartupRules`：依名稱合併 defaults／file／environment／cli，複製並封存設定，錯誤只包含 key。
- `runtime.New`／`Participant`／`WorkGroup`：先停 Ready／接入及認領，再 Drain／取消、反序 Stop，最後關閉 Container 所有資源。
- `uow.NewManager`／`Resource`／`Transaction`／`Check` 與 `postgres.Resource`：M1 Required 交易薄片。RequiresNew、非交易模式及 RepeatableRead／Serializable 明確拒絕；不宣稱完成 M2。Adapter 的 executor 不提供 Begin／Commit。
- `authn.Validator`／`scope.NewTenantResolver`：可信 RS256 identity 與 tenant-only binding；非 Tenant hint 拒絕。
- `distributed.Encode`／`Decode`：明示 snake_case wire envelope；`events/nats` 以 JetStream durable publish ACK 驗證可靠目的地。
- Bookstore 提供兩個獨立程序及 sqlc v1.31.1 的可重現 query source／生成物；queue 與 read-model 實作為 M1 範例薄片，完整通用 Adapter 及可靠性矩陣留待 M3。

M0 沒有 Runtime 使用者需要遷移；採用者改用以上建構入口組裝 Port。`scripts/check.*` 現在執行 M1 完整 Gate，需要明示隔離環境及 `docs/guides/m1-development.md` 的連線環境變數。CI 依賴從 stdlib-only 改為固定 pgx／NATS clients，新增 module checksum 與逐 module 授權 hash allowlist。
