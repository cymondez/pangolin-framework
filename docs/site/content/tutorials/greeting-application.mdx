完成這個教學後，你的應用會從設定層讀取名字，透過自己定義的 `GreetingService` 輸出問候訊息。

先完成[第一個應用](../getting-started/quickstart.mdx)。仍使用同一個 `hello-pangolin` 專案，不需要新增依賴或外部服務。

## 1. 認識這次新增的服務

`GreetingService` 是你自己的 Go 型別，提供 `Greet(name)` 方法。把服務以建構子註冊到依賴注入（Dependency Injection，DI）組合引擎，需要時才解析；測試時可以換成別的實作。

一般應用服務以具象型別直接註冊即可，不需要先定義介面；要讓其他模組使用你的服務時，才把介面放進可 import 的 contracts 套件，見[依賴注入](../fundamentals/dependency-injection.mdx)。

## 2. 設定名字的來源

程式先在 `Configure` 用 `b.SetDefault("app.name", "World")` 宣告模組預設值。如果終端機設定了 `APP_NAME` 環境變數，`main` 會以 `app.Sources` 加上 environment 層覆寫預設。設定優先序是「內建與模組預設 < 檔案 < 環境 < CLI」，右邊的來源覆寫左邊。

在 `Configure` 中以 `module.AddSingleton(b.Services(), NewGreetingService)` 註冊建構子：解析鍵是建構子的精確回傳型別 `*GreetingService`，singleton 表示整個應用只建立一份；需要 transient 或 operation 時分別使用 `module.AddTransient`／`module.AddOperation`，都可與 `module.As(contract)` 組合。`Start` 用 `module.Resolve[*GreetingService](ctx, rt.Services())` 取得具型別服務，並以 `rt.Config().Lookup("app.name")` 讀取設定。底層 `di.Resolver.Resolve` 仍保留為相容 API。

## 4. 執行並改變設定

先執行 `go run .`，預期輸出：

```text
Hello, World!
```

Windows PowerShell：

```powershell
$env:APP_NAME = 'Reader'
go run .
Remove-Item Env:APP_NAME
```

macOS／Linux：

```bash
APP_NAME=Reader go run .
```

這次應該看到 `Hello, Reader!`。
