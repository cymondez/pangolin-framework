完成這個教學後，你的應用會從環境讀取名字，透過自己定義的 `GreetingService` 輸出問候訊息。

先完成[第一個應用](../getting-started/quickstart.mdx)。仍使用同一個 `hello-pangolin` 專案，不需要新增依賴或外部服務。

## 1. 認識這次新增的服務

`GreetingService` 是你自己的 Go 型別。它提供 `Greet(name)` 方法，並透過 constructor 資料接收輸出位置。

應用將服務註冊到 DI（Dependency Injection，依賴注入）容器，之後需要它時再取得。這樣可以在測試時換成別的實作或輸出位置。

## 2. 設定名字的來源

程式預設使用 `World`，如果有 `APP_NAME` 環境變數，則用它覆寫 `app.name`。Module 啟動時透過 `app.Config().Lookup("app.name")` 讀取。

在 `Configure` 中使用 `b.Provide` 註冊服務；`di.Singleton` 表示整個應用只建立一份。`Start` 取得它並呼叫 `Greet`。

## 4. 執行並改變設定

先執行 `go run .`，預期輸出：

```text
Hello, World!
```

Windows PowerShell：

```powershell
$env:APP_NAME = 'Reader'
go run .
Remove-Item Env:APP_NAME
```

macOS／Linux：

```bash
APP_NAME=Reader go run .
```

這次應該看到 `Hello, Reader!`。
