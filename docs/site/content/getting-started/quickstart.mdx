這一頁會建立一個能直接執行的 console 應用。它以 root 裝配啟動一個名為 `hello` 的功能模組、印出訊息，再正常停止。

## 開始前

先完成[安裝與建立專案](installation.md)。以下操作都在你自己的 **`hello-pangolin`** 資料夾進行。

## 1. 建立 main.go

建立 `main.go`，貼上完整程式：

<CodeBlock language="go" title="hello-pangolin/main.go">{source}</CodeBlock>

## 2. 執行應用

```bash
go mod tidy
go run .
```

你應該看到：

```text
Hello, panGOlin!
```

程式在約一秒後正常結束。`app.Run` 會一直運行到 context 結束：真正的長駐應用會把 Ctrl+C 或關閉訊號的 context 交給它；這裡的 `context.WithTimeout` 用一秒期限代表一次示範執行。

## 3. 改成你的訊息

找到 `Start` 裡的 `fmt.Println`，改成：

```go
fmt.Println("Hello, my application!")
```

再次執行 `go run .`，確認輸出已改變。

## 剛才用了什麼？

- **Module** 用普通 Go struct 型別宣告：`module.Base` 提供名稱與版本，`Start` 方法是它啟動時要執行的工作。
- **`app.Run(ctx, root)`** 把根模組交給 kernel runtime：組合設定層、驗證模組相依，先完成所有模組的組態與服務組裝才依序 Start，context 結束時反序 Stop。uow 等必要的啟動預設已由 `app.Run` 內建，不需要額外設定。
- **context** 攜帶取消與逾時；把期限傳給 `app.Run` 一起收尾（含 Stop）。
